# LedgerForge - Release Notes

## Version 1.0.0

### Features
- Employee management with search and pagination
- Department and role management
- Salary history APIs
- Authentication and role-based access control
- Statutory reporting
- Financial reports: Trial Balance, Profit and Loss, Balance Sheet
- Payroll processing workflow
- Database-aware health check
- JSON-formatted logging
- Employee CSV export
- Incremental employee export using date filter

### Verification

- Database connection verified
- Health endpoint verified
- Employee CSV export route verified locally
- Existing project verification script executed
